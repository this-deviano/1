# AMM-004 — RATIFICATION PATHS

Prepared by SB-007-A (TASK-045) on branch `ratify/m1-exit`. **Staged, not executed:** this
amendment takes effect when the maintainer merges that branch, and that merge IS the
ratification. Filed per AG-05 (never edit Genesis in place; proposals to `docs/amendments/`).

The ruling text follows verbatim, as briefed.

── AMM-004 — RATIFICATION PATHS ──
Milestone-exit ratification authority belongs to the maintainer
alone. The agent may prepare artifacts; it never executes.
Path A (full): maintainer executes the human kit; results in
docs/evidence/kit/hv-*.md; ratification commit cites them.
Path B (proxy): maintainer elects to ratify on automated proxy
evidence. Each human-verifiable item is logged HV-DEFERRED with:
the proxy number standing in, a re-verification trigger (first
runtime session; hard gate: 1.0/M8 exit), and priority over
feature work at the next milestone boundary.
Proxy ratification is a debt, not a waiver. All HV-DEFERRED
items MUST clear before 1.0.
The election is recorded in the maintainer's merge commit
message at merge time (templates in MERGE-PLAN.md).
── end ──

Merge-message templates and the post-merge check live in `MERGE-PLAN.md` at the repo root.
The HV-DEFERRED rows this amendment defines (Path B) are in `TASKS.md`.
