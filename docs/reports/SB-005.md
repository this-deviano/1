## 4. The TASK-026 bisect (what was actually established)

Six discriminators, each ruled by measurement rather than argument:

- **STEP 0** — the offline path is **native**: `renderWav → renderBuffer` builds an
  `OfflineAudioContext` and executes `OscillatorNode`, `BiquadFilterNode`,
  `DynamicsCompressorNode`, `StereoPannerNode`, `GainNode`, `AudioBufferSourceNode`.
- **STEP 1** — every `ctx.currentTime` read sits in the *live* path. No clock reads in
  the offline path. Ruled out.
- **STEP 2** — with `Date.now` *and* `performance.now` frozen, a 64-voice render still
  produced 4 distinct hashes in 4 runs. Not clock leakage.
- **STEP 4** — same page: 4 distinct hashes. Fresh page per render: 4 distinct hashes.
  Not in-process state, caches, or a reused buffer (Branch B ruled out).
- **STEP 3 / LADDER A** — every minimal graph and every node class, up to the full
  `osc→biquad→panner→compressor→master` chain, was **bit-stable** across 5 renders.
  **No node class introduces variance** (Branch C ruled out — rungs B3/B4/B6 contain
  no noise source and no PRNG at all, and still vary).
- **STEP 5** — the app-controlled leg is bit-identical measured: 20,000 PRNG draws and
  the model→event list each hashed identically across 4 runs.

**The decisive measurement — variance scales with graph size** (LADDER B, 5 renders
each, one process, app-length render 423,529 samples ≈ 9.6 s):

| graph | distinct hashes | max&#124;Δ&#124; | dBFS |
| ----- | --------------- | ----------- | ---- |
| 1 osc + chain | 1 | 0 | bit-identical |
| 16 osc + chain | 1 | 0 | bit-identical |
| 64 osc + chain | 5 | 2.980e-8 | −150.5 |
| 256 osc + chain | 5 | 5.880e-5 | −84.6 |
| 256 noise + chain | 5 | 2.980e-7 | −130.5 |
| 1024 osc + chain | 5 | 5.775e-4 | −64.8 |

**Branch A: platform WebAudio render noise, size-dependent.** The exact internal
mechanism was *not* isolated and is not claimed — established is the branch.

A genuine epistemic win recorded for honesty: SB-004's "platform float noise"
hypothesis happened to be right, but it was right **by luck**. The bisect showed that
no *specific node class* is responsible, which SB-004's reasoning had assumed.
